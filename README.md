# Сайт риелтора Василия Негрея

Одностраничный адаптивный сайт с описаниями районов Краснодара, фотогалереями и контактами.

## Файлы сайта

- `index.html` — страница сайта.
- `assets/vasiliy-portrait.png` — портрет для первого экрана.

При загрузке на GitHub сохраните папку `assets` рядом с `index.html`.

## Публикация через GitHub Pages

В настройках репозитория выберите **Settings → Pages → Deploy from a branch → main → /(root)** и нажмите **Save**.

Фотографии районов загружаются с Unsplash и служат иллюстрациями. Перед рекламным использованием замените их на фотографии конкретных районов и объектов.

На сайте указаны телефон и Telegram Василия Негрея.
